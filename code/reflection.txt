Working through this pipeline clarified how important lineage and grain are for keeping each step clean and testable. I learned to use element functions with Series.apply for coercing messy HR text, and row apply (axis=1) only when multiple columns from the same row are needed. The left merge made the unmatched-employee logic work naturally, with NaN rates flowing into classify_pay and then into the warning in the app. The consistent copy-add-return pattern and boolean indexing kept every transform predictable, and building the export as a new DataFrame helped me avoid mutating pipeline structure. Going forward, I'll sketch the lineage first so I don't mix grains or hide logic in the wrong place.
